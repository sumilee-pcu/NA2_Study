# NA2 Study — 학습 분석 통합판

대상 저장소: https://github.com/sumilee-pcu/NA2_Study

추가 기능: **학습 분석·오답** 메뉴에서 이론·필기·실기 학습률, 정답 달성률, 과목별 성적, 점수 추이, 통합 오답과 전체 브라우저 기록 내보내기를 이용합니다. [원본 분석 및 구현 보고서](docs/SOURCE_ANALYSIS.md).

로컬 실행: npm ci 후 npm run dev. 배포: GitHub 저장소 Settings → Pages → Source를 GitHub Actions로 설정합니다. 아래 원본 설명과 검증 문서는 기준 저장소의 이력입니다.

- 공개 사이트: https://sumilee-phd.github.io/NA2-study/
- 소스 리포: https://github.com/sumilee-phd/NA2-study
- `127.0.0.1` 주소는 개발 PC의 로컬 미리보기입니다. 다른 기기에서는 공개 사이트를 이용합니다.

2026-10-23 업데이트에는 실기 3영역 메뉴, 검수된 24문항의 문제풀이·채점·복습, Windows·라우터 실습 8개와 입력값 점검 44개가 포함됩니다. 공개 사이트 적용 이력은 [배포 검증](docs/DEPLOYMENT.md)에 기록합니다.

제목에는 Gmarket Sans Bold, 본문에는 Paperlogy Regular를 적용하고 케이블링 선택 탭·답안의 hover 색상 오류를 수정했습니다. 글꼴은 앱에 포함하며 출처·라이선스는 [글꼴 안내](docs/FONTS.md), 실제 화면 검증은 [글꼴·선택 색상 검증](docs/TYPOGRAPHY_VERIFICATION.md)을 참고합니다.

## 포함 기능

- 학습센터: 초기 이론 10개, 자체 개념 확인 20문항, 학습 안내, FAQ 12개, 준비물 8종, 별도 학습 기록과 백업.
- 필기: 기존 900문항, 회차 연습·실전 시험·오답·북마크·기록. 원문을 검토한 8문항에서 관련 이론으로 이동.
- 실기 홈: 작업형·실습형·단답형/객관식으로 구분한 영역 안내.
- 작업형: 기존 케이블링의 개념·22개 문항 템플릿·제작 연습·핀별 진단·선택 복습·배열 교정·무힌트 재평가 유지.
- 실습형: Windows IPv4·DHCP·DNS 레코드·SOA, 라우터 모드·인터페이스·정적 경로·콘솔/VTY의 8개 과제. 조건·절차·입력값 점검·풀이·오류 예방·공식 근거를 제공하며, 초안과 확인 결과를 복원합니다. 실제 명령 실행과 장비 채점 기능은 포함하지 않습니다. 라우터 4개 과제의 명령 수락·저장은 ICQA 라우터 시험 데모에서, Windows 4개 과제의 입력·저장·재확인은 ICQA Windows 실습용 에뮬레이터에서 확인했습니다. ICQA 라우터 데모가 지원하지 않는 콘솔/VTY 과제의 VTY 원격 인증과 유휴 종료, 인터페이스·정적 경로·저장 후 재부팅 복원, IPv4·DNS·DHCP 보완 실험은 Cisco Packet Tracer 시뮬레이션에서 따로 확인했고 DNS·DHCP 일부는 부분 확인으로 남았습니다.
- 단답형/객관식: 검수된 24문항의 전체·유형·주제별 풀이, 문항별 채점·해설·출처 확인, 오답·미응답 복습, 시도 이력, 진행 복원, 기록 백업 내보내기.
- 처음에는 학습센터만 열며 필기 데이터는 필기 모듈 진입 후 불러옵니다. 한 번 연 모듈은 이론을 읽는 동안 유지합니다.

이론은 초기 핵심 주제 수록분으로 전체 시험 범위를 다룬 완성 요약집이 아닙니다. 자체 개념 확인과 케이블링 연습은 공식 기출시험이 아닙니다. 필기 기출 채점은 원본 자료의 가채점 답안표를 따릅니다. 앱은 실물 케이블의 압착·접촉·링크 성능을 측정하지 않습니다.

## 실기 메뉴와 문제은행

| 주소 | 내용 |
|---|---|
| `#/practical` | 실기 3영역 홈 |
| `#/practical/work` | 작업형 안내와 케이블링 연결 |
| `#/practical/lab` | Windows·라우터 실습 8개 목록 |
| `#/practical/lab/{id}` | 조건·설정 절차·입력값 점검·풀이·공식 출처 |
| `#/practical/questions` | 단답형/객관식 풀이·해설·오답 복습·기록 |
| `#/cabling` 이하 | 기존 케이블링 학습·훈련·기록 |

초기 검수 자료는 `content-review/practical-bank.v1.json`에서 관리합니다. 교육용 재구성 문항 24개(단답형·단일선택·복수선택 각 8개)의 원문 쪽수·보완 근거·수정 이유·검토 상태를 기록했습니다. 실제 시험의 문항 비율이나 공식 기출문제로 표시하지 않습니다. 생성 스크립트는 `approved` 문항만 `src/content/practical-questions.json`으로 변환하며, 학생 앱은 이 데이터를 사용합니다. 문항 제출 후 정답·해설·PDF 쪽수·1차 근거 링크를 표시합니다.

단답형은 문항별 허용 답안과 정규화 규칙으로 비교하고, 복수 선택형은 정답 집합과 정확히 일치해야 정답입니다. “모르겠어요”는 정답으로 처리하지 않고 미응답으로 기록합니다. 가장 최근 제출이 오답·미응답인 문항을 복습 목록에 모으며, 재풀이에서 맞히면 목록에서 해결되지만 이전 시도와 원래 답안은 남습니다.

이 기능은 문항별 피드백을 제공하는 학습용 연습입니다. 모의시험·타이머·힌트·백업 가져오기와 자체 라우터·Windows Server 시뮬레이터는 이번 범위에 포함하지 않습니다. 정답 데이터가 브라우저에 전달되므로 감독 시험용 보안을 보장하지 않습니다.

## 실행

```sh
npm ci
npm test
npm run dev
npm run build
npm run preview
```

기본 로컬 주소는 `/`이며 GitHub Actions에서는 저장소명으로 기본 경로를 정합니다. `BASE_PATH=/NA2-study/`를 지정하면 동일한 하위 경로에서 미리 볼 수 있습니다. `main` 브랜치에 푸시하면 테스트·빌드 성공 후 GitHub Pages로 자동 배포됩니다. Actions의 `Deploy Pages`에서 수동으로 다시 실행할 수도 있습니다.

## 기록

기존 `na2_study_learning_v1`, `na2_study_written_v1`, `na2_study_cabling_v1` 키를 유지하고, 단답형/객관식은 별도 `na2_study_practical_v1` 키에 저장합니다. 기존 독립 앱의 기록을 자동으로 가져오거나 변경하지 않습니다. 이론·필기·케이블링 기록은 각각 해당 화면에서 백업합니다.

실습 자료는 `na2_study_labs_v1`에 입력값·확인 여부·풀이 참고 여부를 별도로 저장합니다. 수정하면 이전 판정을 해제하며, 해설을 열거나 오답 기준값을 확인한 뒤 완료하면 도움을 참고한 학습으로 표시합니다. 기존 시험 점수와 제출 횟수를 변경하지 않습니다. 저장 실패·손상·탭 충돌은 원문을 덮어쓰지 않고 자동 저장을 중단합니다. 현재 입력 백업을 제공하며 메뉴 이동 중에는 미저장 입력도 유지합니다. 새로고침·종료 전에는 백업이 필요하고, 실습 백업 가져오기는 지원하지 않습니다.

단답형/객관식은 입력 초안·진행 위치·제출 결과·시도 이력을 저장하여 새로고침 후 이어갈 수 있습니다. 기록 파일 내보내기를 제공하며 가져오기는 후속 범위입니다. 손상·지원하지 않는 버전·저장 오류·다른 탭과의 충돌을 감지하면 자동 저장을 중단하고 보존한 원본을 백업할 수 있게 합니다. 오류가 난 기록을 정상 빈 기록으로 덮어쓰지 않습니다.

자동 저장 한도는 UTF-8 5MiB·제출 20000회이며 브라우저 자체 할당량에 따라 더 일찍 실패할 수 있습니다. 저장 중단 후에도 현재 탭에서 풀이와 내보내기를 계속할 수 있지만 새로고침·탭 종료 전에는 현재 기록을 백업해야 합니다. 다른 메뉴를 오갈 때는 저장되지 않은 현재 풀이도 유지합니다. 동시 쓰기는 변경 감지와 저장 전 원문 비교로 보호하며 다중 사용자 동기화나 원자적 잠금을 제공하지 않습니다.

필기나 케이블링 평가를 진행 중이면 이론과 실기 안내뿐 아니라 단답형 문제·해설·오답 기록 화면도 가립니다. 필기 시험 시간은 계속 흐릅니다. 이는 앱 내부 학습 흐름이며 외부 자료 열람을 통제하는 시험 감독 기능이 아닙니다.
