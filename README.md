# NA2 PCU — 네트워크관리사 2급 학습 프로그램

원본 `sumilee-phd/NA2-study`의 학습 자료·문제풀이를 기반으로 `sumilee-pcu/NA2_Study`에서 고도화한 브라우저 학습 앱입니다.

## 고도화한 학습 흐름

최상위 메뉴는 **학습 현황 / 이론 / 필기 / 실기 / 오답 노트 / 학습 기록**입니다. 첫 접속 시 학습 현황을 표시합니다.

- **이론**: 10개 핵심 주제, 20개 개념 확인, 읽음 표시, 관련 필기 연결.
- **필기**: 900문항, 과목·회차별 연습, 실전 평가, 문항별 채점·북마크.
- **실기**: 케이블링, Windows·라우터 실습 8개, 단답·객관식 24문항을 구분.
- **통합 오답 노트**: 이론·필기·실기 문제·케이블링·실습의 미해결 항목을 수집. 영역·문항 검색, 복습 체크, 틀린 이유 메모를 브라우저에 저장. 체크와 정답 판정을 분리하며 재풀이에서 정답이면 해결.
- **학습 분석**: 다섯 영역별 풀이 학습률, 정답 달성률, 풀이 정답률. 필기 과목별 누적 정답률·최근 점수 차트·평균 변화. 영역별 다른 평가를 합격 확률로 합산하지 않음.
- **통합 기록**: 이론 최신 개념 확인, 필기 회차 점수, 실기 문제·케이블링 제출 이력의 영역별 조회와 페이지 이동.
- **백업·복원**: 전체 JSON 다운로드, 가져오기 검증, 영역 교체 미리 확인, 복원 전 원문 안전 백업, 다른 탭 변경 감지 및 저장 실패 시 되돌리기. 백업에 없는 영역은 그대로 유지.

## 실행

Node.js 22 이상에서:

```sh
npm ci
npm test
npm run dev
```

개발 주소: http://127.0.0.1:5173

```sh
npm run build
node serve.mjs
```

빌드 실행 주소: http://127.0.0.1:5174
Windows에서는 빌드 후 `start-local.cmd`로 실행할 수도 있습니다.

## GitHub Pages

저장소 Settings → Pages → Source에서 **GitHub Actions**를 선택해야 합니다. main에 push하면 테스트·빌드 이후 배포됩니다. 예정 주소: https://sumilee-pcu.github.io/NA2_Study/ (배포 성공 전에는 접속되지 않습니다).

## 기록과 점수의 범위

브라우저 localStorage에만 기록합니다. 다른 기기·브라우저·도메인·포트 간 자동 동기화는 하지 않습니다. 브라우저 데이터 삭제 전 백업하세요. 필기 진행 중 세션이 포함된 전체 백업은 제출 후 다시 내보내야 통합 복원할 수 있습니다. 저장 중단 상태의 입력은 해당 모듈에서 별도 백업하세요. 원문 안전 백업은 복구용 파일이며 일반 가져오기 파일과 구분됩니다.

이론은 초기 핵심 주제 수록분입니다. 필기는 원본 가채점 답안을 따릅니다. 실습 점수는 입력값 검사이며 실제 장비 실행이나 시험 합격을 보증하지 않습니다. 복습 체크만으로 점수가 올라가지 않습니다.
