# PCU 고도화 검증

## 원본과 달라진 동작

1. 학습센터 중심 초기 화면 → 점수·범위 분석 중심 첫 화면, 독립된 여섯 개 최상위 메뉴.
2. 모듈별 오답 → 다섯 영역 통합 오답 목록, 필터·검색·복습 체크·메모. 수동 복습 체크는 정답으로 취급하지 않음.
3. 분산 기록 → 통합 제출 이력과 전체 백업 복원. 가져온 영역만 교체하고 파일 검증·동시 변경 검출·복원 실패 되돌리기 적용.
4. 필기 중심 분석 → 이론·필기·실기 문제·케이블링·Windows/라우터 실습의 다섯 영역별 학습률과 정답 달성률.

## 검증 결과

- 자동 테스트 124개 통과. 원본 테스트와 신규 분석·백업 복원 테스트 포함.
- 신규 테스트: 잘못된 백업 거부, 동시 변경 시 쓰기 차단, 저장 공간 실패 시 이전 값 복원, 백업에 없는 영역 보존, 복습 체크와 점수 분리.
- 프로덕션 빌드 및 빈/성적 기록 대시보드 렌더링 통과.
- 브라우저 자동화는 Windows 실행 환경 오류(permission path cannot be represented losslessly)로 시작되지 않아 실제 클릭·시각 검증은 미완료.
- GitHub Pages는 저장소 소유자의 Source=GitHub Actions 설정이 필요. 배포 성공을 별도로 확인하기 전 공개 실행 완료로 간주하지 않음.

## 제한

- 이론 개념 확인의 과거 시도 전체는 원본 저장 형식에 없으므로 최신 기록만 표시.
- 실습은 최신 설정 검사 결과만 있으며 제출 시간 이력은 없음.
- 필기 진행 세션이 든 전체 백업은 제출 후 다시 내보내야 복원 가능.
- localStorage 다중 키 복원은 원자적 트랜잭션이 아니며, 실패 시 되돌리기를 시도. 되돌리기까지 실패하면 원문 안전 백업을 이용한 별도 복구 필요.
