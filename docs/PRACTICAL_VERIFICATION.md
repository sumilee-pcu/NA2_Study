확인일: 2026-10-23 · 로컬 Windows · 브랜치 `codex/practical-sections-prd`

## 완료 범위

실기 홈과 작업형·실습형·단답형/객관식 안내를 구현했다. 기존 케이블링으로 연결하고, 실습형은 ICQA 공식 프로그램 안내를 제공한다. 문제풀이와 별도 웹 라우터 실습실은 준비 중으로 표시한다. [실기 PRD](PRACTICAL_PRD.md)와 [콘텐츠 검수 보고서](PRACTICAL_CONTENT_REVIEW.md)에 후속 구현 조건과 초기 데이터의 한계를 기록했다.

초기 문제은행은 교육용 재구성 문항 24개이며 단답형·단일선택·복수선택 각 8개이다. 원문 취지 확인 8개, 조건 명확화 10개, 오류 교정 6개이고, 별도 목록에 제외 6개·보류 4개를 남겼다. 유형별 수량은 실제 시험 비율을 의미하지 않는다.

최종 빌드 명령:

```powershell
& 'C:\Users\user\.cache\codex-runtimes\codex-primary-runtime\dependencies\node\bin\node.exe' node_modules/vite/bin/vite.js build
```

시스템 Node로 시도한 첫 빌드는 종료 코드 1을 반환했으나 원인 진단이 나오지 않았다. 번들 Node로 실행한 빌드는 성공했으며 최종 화면 수정 후 다시 성공했다. 테스트 성공과 공식 실습 프로그램 실행 성공을 혼동하지 않는다.

## 브라우저 확인

Windows의 Codex 내장 브라우저에서 로컬 `127.0.0.1:5177` 개발 서버를 확인했다. 실제 공개 사이트의 배포 검증은 아니다.

|---|---|
| 실기 홈과 3영역 카드 | 각각의 기능·준비 상태와 이동 링크 표시 |
| `#/practical`, `/work`, `/lab`, `/questions` | 4개 화면의 직접 진입·새로고침 후 제목과 내용 유지 |

| 기존 `#/cabling` | 기존 대시보드·훈련 화면 표시, 실기/작업형 메뉴 선택 상태 유지 |

| 평가 상태 복원 | 핀·색상 평가의 선택 답안이 실기 안내 이동·새로고침·평가 복귀 후 동일하게 남음 |
| 테스트 평가 종료 후 실기 홈 | 정상 안내 다시 표시. 검수용 로컬 연습으로 전환했고 실제 학생 기록은 사용하지 않음 |

새 단답형 채점 엔진과 기록 저장은 아직 구현하지 않았다. 따라서 이 문서의 데이터 검사를 실제 답안 입력·채점·오답 저장 검증으로 해석하지 않는다. 이번 브라우저 상태 보존 검사는 기존 케이블링 평가에 대한 것이다.
