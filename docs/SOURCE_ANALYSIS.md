# 원본 분석 및 구현 보고서

분석 기준: sumilee-phd/NA2-study, commit a01aec20d1313f71296889bb946fe850f457451e (2026-10-28).
대상: sumilee-pcu/NA2_Study. 작업 시작 당시 빈 저장소.

## 구조와 기능
- React 19 + Vite 6, 해시 경로를 사용한 정적 브라우저 앱. 서버·계정 없이 동작.
- 이론: 10개 주제 / 자체 개념 확인 20문항. 읽기 표시·검색·관련 문제 연결.
- 필기: 900문항, 원문 이미지와 가채점 답안, 회차·과목 필터, 실전/연습, 오답·북마크. 문제은행 약 25 MB는 필기 진입 후 지연 로드하고 Cache Storage에 저장.
- 실기: 케이블링 22개 템플릿, 단답/단일/복수선택 24문항, Windows/라우터 8과제와 44개 설정값 확인.
- 모듈마다 독립된 localStorage 키를 사용. 실기와 이론은 검증·저장 충돌 보호를 갖춤. 필기는 읽기 복구 검증이 상대적으로 약함.
- 기존 테스트, 검수 기록, 출처 및 글꼴 라이선스 파일을 보존.

## 추가 구현
- 상단 이론·필기·실기 구분, 학습센터에 학습 분석·오답 메뉴.
- 통합 오답: 이론 개념 확인 / 필기 / 실기 단답·객관식의 최신 결과. 재정답 시 해결. 필기 미응답은 원본 정책대로 미풀이이며 통합 오답에 포함하지 않음.
- 학습률 = 풀이 고유 문항 수 / 전체 문항 수. 정답 달성률 = 최신 정답 고유 문항 수 / 전체 문항 수. 풀이 정답률 = 최신 정답 / 풀이 고유 문항 수.
- 필기 과목별 누적 정답률은 재풀이를 포함한 전체 응답 횟수로 산출.
- 최근 5회 평균, 이전 최대 5회 대비 점수 변화, 최근 12회 점수 차트·표. 기록 없을 때 점수를 0으로 추정하지 않고 — 표시.
- 실습 확인·정답 과제 수·해설 참고, 케이블링 누적 응답·정답률 별도 표시.
- 통합 JSON 내보내기는 다섯 모듈의 저장 기록을 그대로 보관. 전체 묶음 가져오기는 지원하지 않으며 기존 각 영역의 백업 메뉴 유지.
- 문항 색인은 scripts/make-index.mjs로 실제 필기 자료에서 생성. 통계 진입 시 대용량 문제 원문은 불러오지 않음.

## 해석 및 운영 제한
- 영역별 점수는 공식 합격 확률이 아니며 서로 합산하지 않음. 실습은 입력 확인이고 실제 장비 실행은 아님.
- 이론은 핵심 10개 주제로 전체 시험 범위를 완전히 다루지 않음. 필기 답안은 원본 가채점 자료를 따름.
- 동일 브라우저·동일 origin 내 저장. 다른 PC/브라우저 또는 localhost에서 GitHub Pages로 이동하면 자동 공유되지 않음.
- 저장이 중단된 메모리 내 입력은 통합 저장소 백업에 없을 수 있어 해당 모듈에서 백업 필요.
- 원본 저장소에 최상위 소프트웨어 라이선스 파일은 발견되지 않음. 원본 출처와 포함된 개별 자산 라이선스는 보존했으며 새로운 일괄 라이선스를 부여하지 않음.

## 이번 작업 검증
