# 준비물 사진 출처

확인일: 2026-10-23

`#/learn/tools`의 준비물 8개 제목 옆에 사용하는 실물 사진이다. 사진은 제품 형태의 예시이며 특정 모델의 권장, 시험장 반입 허용 또는 규격 호환을 보장하지 않는다. 표시용 레이블에는 종이 마스킹테이프 사진을 예시로 사용한다.

각 사진은 아래 원본의 라이선스를 유지한다. Wikimedia Commons가 제공하는 원본 또는 축소본을 사용하며 사진 내용을 수정하지 않았다. 앱에서는 전체 사진을 `object-fit: contain`으로 표시한다. 사진을 수정하여 재배포할 때는 해당 라이선스의 조건을 확인한다. CC BY-SA 사진의 조건은 해당 사진에 적용되며 프로젝트의 다른 독립 저작물에 대한 라이선스 선언이 아니다.
