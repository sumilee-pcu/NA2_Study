# NA2 Study 통합 앱 PRD

버전 2.4 · 2026-10-23 · 상태: Windows·라우터 실습 자료 8개와 입력값 점검 44개 확장

## 목적과 변경 범위

사용자의 최종 결정에 따라 기존 필기·실기 리포와 공개 앱을 현재 버전으로 고정하고, 별도 NA2-study 프로젝트를 만든다. 학습센터를 기존 필기 앱에 추가하려던 앞선 제안은 이 결정으로 대체한다. 원본 커밋과 파일 해시는 BASELINES.json에 기록한다. 원본 리포, 원본 배포 설정, 기존 사용자 기록은 수정하지 않는다.

학습 흐름은 개념 이해 → 문제풀이 → 오류 확인 → 교정 → 도움 없이 재확인으로 구성한다. 새 앱은 React/Vite를 사용하고 기존 두 앱의 코드와 문제 데이터를 독립 복사하여 확장한다. 원본 사이트에 iframe으로 의존하지 않는다. 새 GitHub 원격 저장소 공개와 공개 배포는 이 문서의 로컬 구현 완료와 구분한다.

2026-10-23 변경은 기존 실기 24문항 기능에 Windows IPv4·DHCP·DNS와 라우터 실습 자료 8개를 추가한다. 실습 조건·절차·입력값 점검 44개·풀이·공식 근거와 진행 복원을 제공한다. 기존 기능과 기록을 유지한다. 상세 계약은 [실기 PRD](PRACTICAL_PRD.md)를 따른다. 실제 명령 실행·장비 채점, 모의시험·타이머·실기 백업 가져오기는 후속 범위이다. 사용자 요청에 따라 검수 후 커밋과 공개 배포를 진행하며, 실제 성공 여부는 [배포 기록](DEPLOYMENT.md)에서 구분한다.

공통 상단에 학습센터·필기 문제풀이·실기를 배치한다. 실기는 홈에서 세 영역으로 진입하며 기존 `#/cabling` 이하 주소는 유지한다. 이론 상세 주소와 직접 진입·새로고침·브라우저 뒤로 가기를 지원한다. 필기·케이블링 모듈은 최초 진입에만 지연 로딩하고 이후 숨김 상태로 유지하여 이론 왕복에서 답안과 위치를 보존한다. 필기·케이블링 평가가 진행 중이면 공통 이론과 실기 문제·해설·오답 기록을 가리고 해당 평가 복귀 버튼을 제공한다. 첫 진입에서도 새 앱 저장 키의 세션 상태만 읽어 같은 정책을 적용한다.

## 콘텐츠

초기 이론은 필기 4과목 각 2개와 케이블링 2개, 총 10개이다. 개념 확인은 각 2개로 총 20개 자체 문항이다. FAQ 12개, 도구·소모품 8개와 단계별 학습 안내를 제공한다. 전체 시험 범위를 다룬 완성 요약집으로 표시하지 않는다.

이론은 학습 목표, 선수 개념, 설명과 표, 예제, 혼동하기 쉬운 점, 개념 확인, 출처와 검토일을 포함한다. 기술은 공식 문서, 시험 규정은 ICQA 자료를 기준으로 확인한다. 필기 문제와의 연결은 원문을 대조한 8문항부터 시작하며 검색어 일치만으로 연결하지 않는다. 기존 가채점 답안표를 공식 확정 해설로 바꾸거나 덮어쓰지 않는다.

실기 초기 문제은행은 `content-review/practical-bank.v1.json`에서 검수 자료로 관리한다. 원문 쪽수·기술 근거·수정 이유와 검토 상태를 보존하고, 생성 스크립트는 `approved` 24문항을 `src/content/practical-questions.json`으로 변환한다. 단답형·단일 선택·복수 선택 각 8문항이며 실제 시험 비율을 뜻하지 않는다. 검토 대기·근거 불충분 문항은 학생용 데이터에서 제외한다. 학생 화면에는 문항 제출 후 해당 정답·해설·PDF 쪽수·1차 근거 링크를 표시한다. 정답이 포함된 클라이언트 데이터는 감독 시험용 보안을 제공하지 않는다.

## 기록과 채점

이론·필기·실기는 각기 새 저장 키를 사용한다. 기존 독립 앱 기록을 자동으로 읽거나 쓰지 않는다. 이론 열람과 준비물 체크, 교정 완료는 평가 점수에 합산하지 않는다. 각 영역에서 별도로 백업하며 미래 버전·손상 파일은 정상 기록을 자동 덮어쓰지 않는다.

단답형/객관식은 별도 `na2_study_practical_v1` 키를 사용하며 기존 세 기록 키를 유지한다. 문항별 허용 답안·정규화 규칙과 선택지 ID를 기준으로 판정한다. 복수 선택은 정확한 집합 일치만 정답으로 인정한다. 빈 답안 또는 “모르겠어요”는 미응답으로 구분하며 정답으로 처리하지 않는다. 최신 제출이 오답·미응답인 문항을 복습 목록에 포함하고 재풀이 정답이면 해결하되 모든 이전 시도·원래 답안은 보존한다.

초안·진행 위치·제출 결과를 새로고침 후 복원하고 동일 시도의 중복 제출을 막는다. 기록 백업 내보내기를 제공하며 가져오기는 후속 범위이다. 손상·지원하지 않는 버전·저장 오류·탭 충돌 시 자동 저장을 중단하고 원본 백업을 제공한다. 정상 빈 기록으로 자동 교체하지 않는다.

핀 단독 응답과 배열 위치 진단은 각각 A/B×8핀으로 집계한다. 배열 제출 1건에서 8핀을 분석해도 제출 횟수는 1건이다. 미학습은 정답률을 만들지 않는다. 이전 응답에 없는 힌트 사용·수정 횟수·핀별 소요시간은 추정하지 않는다. 진행 중 평가의 정오 정보는 해당 평가 종료 전까지 화면 진단·오답·통계에서 숨긴다.

배열 교정은 교환 전 배열·현재 배열·선택 핀·이동 횟수·완료 기록을 별도로 저장한다. 두 핀을 차례로 선택해 교환하며 키보드도 지원한다. 교정 완료는 퀴즈 응답이나 기존 오답 해제에 사용하지 않는다. 무힌트 재확인은 새 평가로 시작하고 새 제출로 기록한다. 원래 답안과 점수는 보존한다.

## 수용 기준

- 기존 리포 커밋·작업 트리·추적 파일의 SHA-256이 기준과 동일하다.
- 새 학습센터는 bank.json을 요청하지 않고 열리며 필기 진입 후에만 문제 데이터를 가져온다.
- 이론 검색·필터·FAQ 검색의 표시 개수는 실제 결과와 일치한다.
- 개념 확인은 제출 전 정답을 숨기고, 읽음·답안·준비물 상태가 새로고침 후 유지된다.
- 이론과 문제 왕복에서 진행 답안·문항 위치를 유지한다. 필기 실전 타이머는 계속 흐른다.
- 교정 1회 완료가 중복 기록되지 않고 기존 점수·오답 기록을 변경하지 않는다.
- 평가 중 이론·핀 진단·교정으로 진행 평가의 정오 정보가 노출되지 않는다.
- 360px 폭에서 메뉴·도해·핀·교정 조작을 사용할 수 있다.
- 통합 빌드·모델 회귀 검사·실제 브라우저 조작을 완료하고 검증 범위를 문서화한다.
- 실기 홈과 세 영역의 주소에 직접 진입하고 새로고침·뒤로 가기를 사용할 수 있다.
- 기존 케이블링 주소·저장 키·진행 답안·평가 타이머를 변경하지 않는다.
- 초기 문제은행의 출처·검토 상태를 확인할 수 있고 검토 대기 문항과 학생 제공 문항을 구분한다.
- 24문항의 유형·주제 필터 개수가 실제 결과와 일치하고 검수된 정규화 규칙·선택 집합대로 채점한다.
- 오답·미응답의 재풀이 정답은 복습 목록에서 해결되고 이전 시도·원래 답안은 남는다.
- 제출 전 정답을 숨기며, 필기·케이블링 평가 중 새 문제·해설·오답 기록 화면이 차단된다.
- 초안·진행·제출 결과 복원, 중복 제출 방지, 기록 내보내기, 오류·탭 충돌의 자동 저장 중단과 원본 보존을 확인한다.
- 아직 구현하지 않은 모의시험·타이머·힌트·백업 가져오기·별도 실습실을 작동하는 기능처럼 표시하지 않는다. 라우터 연결은 실제 제공 주소가 확정·검증된 뒤 추가한다.

검증의 실제 수행 결과는 [실기 문제풀이 구현 검증](PRACTICAL_QUIZ_VERIFICATION.md)에 기록한다. 기존 초기 문제은행·3영역 메뉴 검증 문서는 당시 단계의 이력으로 보존한다.

실물 제작 품질, 실제 스마트폰 기종별 동작, 전체 시험 범위의 완전한 이론 수록, 계정·서버 동기화·교사 대시보드는 별도 범위이다.
