# 실기 24문항 문제풀이 구현 검증

이 문서는 공개 배포 전 로컬 검수 기록입니다. 이후 완료한 공개 사이트 확인은 [배포 검증](DEPLOYMENT.md)을 참고하세요.

검증일: 2026-10-23 · 환경: Windows / 로컬 Node.js / ChatGPT 내장 브라우저

## 구현 결과

검수한 교육용 재구성 24문항을 `#/practical/questions`에서 풀 수 있다. 단답형·단일 선택·복수 선택 각 8문항이며, 유형·주제 필터와 개별 문항 시작을 제공한다. 제출한 답안은 정답·오답·미응답으로 구분하고 해설·원본 PDF 쪽수·1차 근거 링크를 표시한다.

최신 답안이 오답·미응답인 문항을 복습 목록에 모은다. 재풀이 정답이면 복습 목록에서 빠지고 과거 답안은 시도 이력에 남는다. 초안·현재 문항·제출 결과를 별도 `na2_study_practical_v1` 키에 저장한다. 현재 기록 JSON 내보내기와 오류 상황의 저장 원문 TXT 내보내기를 제공한다.

검수 원본과 실행 데이터의 불일치는 생성 스크립트의 `--check`로 차단한다. 앱에는 승인한 문항과 해당 근거만 포함하며, 제외·판독 보류 항목과 원본 PDF 전체를 새 번들에 넣지 않는다.

## 자동 검증

| 검증 | 결과 | 범위 |
|---|---|---|
| 전체 회귀 테스트 77개 | 통과 | 기존 58개 + 당시 실기 모델 19개 |
| 저장 한도 보완 후 실기 모델 23개 | 통과 | 기존 실기 19개 재검증 + 경계 조건 4개 추가. 최종 테스트 구성은 총 81개이며 전체 81개를 한 명령으로 재실행한 것은 아님 |
| 검수 원본 → 실행 데이터 일치 | 통과 | 승인 문항·허용 답안·출처·필드 검증, 결정적 생성 |
| 배포용 Vite 빌드 | 통과 | `BASE_PATH=/NA2-study/`, 45개 모듈, 최종 빌드 약 1.84초 |
| 원본 앱 보존 | 통과 | `verify-originals.mjs`: NA2-com `7e0c035`, NA2-cabling `8036a54`, 42개 추적 파일 SHA-256 일치 |
| 기존 모듈·공개 데이터 변경 | 없음 | 이번 변경에서 `src/modules`, `public`의 추적 파일 diff 없음 |
| 원본 PDF SHA-256 | 일치 | `31B6F1FCB596EB3E6E60CFBC21DDD994A2C02425B0AFAD8E4D818C0F7A7B8D0E` |
| diff 공백 검사 | 통과 | `git diff --check` |

실기 모델 검증에는 모든 문항의 허용 답안, 문항별 정규화, 복수 선택의 정확한 집합 일치, 중복 제출 방지, 초안·제출 복원, 최신 오답 판정, 과거 이력 보존을 포함한다. 저장소 손상·버전 불일치·읽기 및 쓰기 오류·다른 탭의 변경·추가·삭제·기록 축소 시 기존 저장 원문을 덮어쓰지 않는 것도 검증했다.

자동 저장은 UTF-8 5MiB·20000시도까지이며 브라우저 할당량에 따라 먼저 실패할 수 있다. 2001회 저장·복원, 20000회 경계, UTF-8 바이트 초과 후 메모리 제출·전체 백업을 검증했다. 메모리·백업 검증의 절대 한도는 별도 50MiB·200000시도이며 기록을 자동 삭제하지 않는다.

## 실제 브라우저 확인

| 사용자 흐름 | 확인 결과 |
|---|---|
| 24문항 선택 화면 | 유형·주제·문항 ID·시작 버튼 표시. 단답형/복수 선택 각 8개 필터와 조건 일치 0개일 때 시작 비활성 확인 |
| 단답형 오답 → 정답 재풀이 | PRAC-001 오답 후 해설 표시, 복습 1개. 재풀이 정답 후 복습 0개, 두 답안 모두 이력 유지 |
| 단답형 초안·제출 복원 | 새로고침 후 입력 초안과 제출 완료 피드백 각각 복원. 동일 제출이 다시 이력에 추가되지 않음 |
| 단일 선택 | PRAC-009의 D(16384개) 선택 시 정답·설명 표시 |
| 복수 선택 | PRAC-018에서 A/C만 선택하면 오답, D/A/C 순서로 모두 선택하면 정답. A/C 초안의 새로고침 복원 확인 |
| 미응답 | PRAC-003에서 “모르겠어요” 선택 시 미응답 저장·정답/해설 표시·복습 목록 포함 |
| 진행 중 풀이 교체 | 확인창 취소 시 PRAC-004 초안 유지, 확정 시 PRAC-005 빈 답안으로 새 풀이 시작 |
| 탭 간 변경 감지 | 탭 A에서 초안 변경 후 탭 B 자동 저장 중단 경고. B의 미저장 초안은 실기 홈 왕복 후에도 유지되고 계속 채점 가능 |
| 백업 파일 실제 다운로드 | 탭 B의 현재 JSON에는 7회와 미저장 답안, 저장 원본 TXT에는 기존 6회와 탭 A 초안 `ICMP`가 포함됨. 실제 파일을 JSON 파싱하여 확인 |
| 기존 평가 보호 | 케이블링 평가 중 문제풀이 경로 접근과 새로고침 모두 차단. `.hub-quiz` DOM 0개. 평가 복귀 후 연습 전환과 실기 화면 복귀 확인 |
| 모바일 화면 | 360×800 뷰포트에서 목록·필터·복수 선택·채점/해설·학습 기록 확인. 가로 넘침 없음, 캡처 육안 확인 |
| 배포 경로·연속 풀이 | `/NA2-study/#/practical/questions` 직접 진입, 단답형 8문항 시작, 첫 문항 정답 후 다음 문항 이동, 두 번째 문항 위치와 초안 새로고침 복원 |
| 브라우저 콘솔 | 개발 서버 및 배포용 미리보기에서 수집된 오류·경고 없음 |

브라우저 검증은 `127.0.0.1:5178` 개발 서버와 `127.0.0.1:5179/NA2-study/` 배포용 미리보기에서 수행했다. 공개 사이트의 학생 기록을 사용하거나 변경하지 않았다.

## 로컬 증거

`verification/practical-quiz-20261023/`에 테스트 로그·빌드 로그·브라우저 캡처·다운로드 백업 사본을 보관했다. 이 폴더는 기존 `.gitignore`에 따라 로컬 검증 자료이며 Git 배포 대상이 아니다.

## 참고자료와 한계

추가로 받은 Velog 글은 [참고자료 검토](PRACTICAL_REFERENCE_REVIEW.md)에 주제 연결·교정 5항목·후속 후보를 기록했다. 블로그를 근거로 기존 24문항의 채점 기준을 바꾸거나 새 문항을 추가하지 않았다.

- 로컬 구현·검증 완료이며 공개 배포·Git push는 수행하지 않았다.
- 모바일은 브라우저 뷰포트 확인이며 실제 Android/iOS 기기·Safari 검증은 수행하지 않았다.
- 손상/용량 초과는 모델 테스트에서 검증했다. 실제 브라우저 저장소 손상 주입이나 디스크 할당량 소진 실험은 수행하지 않았다.
- 저장 충돌은 변경 감지와 저장 전 원문 비교로 보호하며 원자적 다중 쓰기 잠금이나 기기 간 동기화는 아니다. 저장 중단 시 새로고침·탭 종료 전에 현재 기록을 내보내야 한다.
- 이번에는 백업 내보내기만 제공한다. 가져오기·모의시험·타이머·힌트·라우터/Windows Server 자체 시뮬레이터는 후속 범위이다.
- 클라이언트 학습 앱에 정답 데이터가 포함된다. 기존 평가 차단은 학습 동선 보호이며 감독 시험 보안으로 해석하지 않는다.

기존 초기 검수·메뉴 단계의 [검증 문서](PRACTICAL_VERIFICATION.md)는 당시 이력으로 유지한다.
