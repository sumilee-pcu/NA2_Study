# 글꼴 및 선택 색상 수정 검수

이 문서는 공개 배포 전 로컬 검수 기록입니다. 이후 완료한 공개 사이트 확인은 [배포 검증](DEPLOYMENT.md)을 참고하세요.

검수일: 2026-10-23. 대상: 통합 앱 `NA2-study`. Windows의 Chromium 기반 브라우저에서 개발 서버와 배포용 빌드를 확인했습니다.

## 변경 사항

- 페이지·절 제목: Gmarket Sans Bold 700.
- 본문: Paperlogy Regular 400. 메뉴·짧은 강조에는 Paperlogy SemiBold 600을 함께 포함했습니다.
- `src/typography.css`에서 공통 글꼴을 지정하고, 나중에 로드되는 필기·케이블링 CSS에도 유지되도록 선택자를 구성했습니다.
- FAQ 질문과 답변: 데스크톱 15px, 모바일 14px. 답변은 Regular 400, 행간 1.9입니다.
- 케이블링의 일반 버튼 hover에서 `.selected`, `.chosen`을 제외했습니다. 선택된 탭·답안·교정 핀의 배경과 테두리를 유지합니다. `:where()`를 사용해 기존 메뉴 hover의 우선순위는 높이지 않았습니다.
- 단답형 화면이 참조하던 공통 본문 색상 `--hub-ink`를 `#192d33`으로 명시했습니다.

웹폰트 3개는 앱에 포함했습니다. 전체 글리프를 보존한 WOFF 파일 합계는 1,486,568바이트이며 초기 방문 시 다운로드 비용이 발생합니다. 외부 폰트 서비스는 호출하지 않습니다. 출처·원본 대조·변환 무결성·동봉 라이선스는 [FONTS.md](FONTS.md)에 기록했습니다. 원본 문제 이미지 내부의 글자는 변경하지 않았습니다.
